# Using your NEXORGE dashboard

Open the public preview and explore Overview. All names and amounts are samples.

1. Select **New project**, add a sample brief, and save.
2. Click a project name to edit its stage, progress and studio notes.
3. Open **Lead pipeline** and use each card’s stage selector.
4. Use **Tasks** to add work and mark it complete.
5. Add shoot days and reviews in **Calendar**.
6. Use **Invoices** for sample tracking; status changes do not send invoices or take payments.
7. Use **Export** to download this browser’s workspace as JSON.

Edits stay only in the current browser. Use Settings → Reset sample data to start again. The reset dialog asks for confirmation.

## To use this with your real team
You will need a private login and a shared database first. Choose who can access projects, finance and client details. Then an authenticated version can be deployed at **dashboard.nexorge.com** after configuring your domain’s DNS. Keep real client information out of this public demo.

The existing nexorge.com website remains unchanged.
